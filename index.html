Moving Head Batch Editor

Scans your rendered xLights sequences, shows which ones drop the moving head beams below the tilt you set, and can add the Additive lift to MH Tilt for you.

Scanning is read-only. Nothing is changed until you confirm an edit in step 4.
STEP 1

Pick your show folder

Choose XLIGHTS\Show DIR. The browser asks for permission to view the folder. It only asks to save changes later, if you choose to edit sequences in step 4. Everything stays on this computer.

No folder chosen yet.

This browser can only read the folder, so step 4 (editing) is turned off. Use Chrome or Edge on your PC to edit sequences.

STEP 2

Set the limit

Tilt is the raw DMX value, 0–255. On your heads a higher value raises the beam, so anything under the lowest value counts as too low. The top limit is optional. Use it if beams also tip too far over the back.

0255

A head can't swing in a split second, so a tilt glitch of a few frames doesn't move the beam. This often happens when a tilt effect ends a frame or two before the dimmer does. Set the dip time to 0 to count every frame.

CheckHeadTilt chDimmer chMH Tilt chOwn lowest

STEP 3

Scan

The scan reads the rendered .fseq file of each sequence, so render first (Tools → Batch Render) if you've changed anything. Big shows take a while. Expect roughly 10–30 seconds per song.

Folders with sequences show up here after step 1.

Click a row to see each head. "Add" is how much the lowest point has to come up to reach your limit. "First dip" is where in the song it first goes too low.

STEP 4

Fix the low sequences

For each sequence you tick, this adds one DMX effect across the whole song on MH Tilt › Strand 1, blended Additive, with DMX1–DMX8 set to the lift for each head. That's the same thing you do by hand. If a sequence already has that lift, its values are raised instead of adding a second one. Your .fseq render files are never touched. You re-render afterwards.

Scan your sequences first. Any that are too low show up here.
How to lift
Make tilt effects Additive

Turn on "Make tilt effects Additive" when the lift doesn't seem to work in a sequence. That happens when the tilt effects on the heads cover the lift. It only changes DMX effects that move the tilt channel, on the head models, groups that hold heads, and MH Tilt's own rows. You can also set it per sequence below.
